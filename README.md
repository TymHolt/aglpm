# AGLPM
**AGLPM** stands for **AG**ile **L**ike **P**roject **M**anager. It is a tool designed to manage
and track progress for projects with *epics* and *tasks* locally.

## Developing
During development, use the following command to run the application, run `run.sh`:

> bash run.sh

This will require **Maven** to be installed ont the system.
